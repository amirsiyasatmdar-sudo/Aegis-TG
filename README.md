# 🛡️ Aegis-TG

**Aegis-TG** is a professional, AI-powered, and threat-intelligence-driven Telegram Management System. It is designed to protect large groups/channels from malicious links, fake bots, phishing attacks, and spam, while providing advanced analytics and management tools.

## ✨ Features
- 🛡️ **Threat Intelligence**: Scans links (VirusTotal), files (YARA), and detects phishing texts using NLP.
- 🤖 **AI-Powered Management**: Summarizes chats, answers questions, and detects spam patterns.
- 📊 **Graph Analytics**: Detects botnets and fake accounts using network analysis.
- ⚙️ **Modular Architecture**: Built with Docker, PostgreSQL, Redis, and Qdrant.
